# Color Based Object Tracking With OpenCV
### detects and tracks an object in a video based on its color

Amazing simple object tracker based on its color. (Used green color in this project)

All thanks to Adrian Rosebrock (from [pyimagesearch](https://www.pyimagesearch.com/)) for making
great tutorials. This project is inspired from his blog: [Ball Tracking with OpenCV](https://www.pyimagesearch.com/2015/09/14/ball-tracking-with-opencv/). I have included the author's code and the one i wrote my self as well.

## **Key Points**
1. Steps involved:
    1. Detect the coloured object in the image.
    2. Track the coloured object as it moves around in the video. Draw it's previous locations.
2. Assumptions:
    1. There is only one object in the image that has the tracked colour.
    2. This is the largest object of that colour in the image.
3. There is support for both recorded video detection and live detection using webcam.
4. We can specify the desired length of contrail size of the object's previous locations.
5. HSV color space is used to detect the coloured object. Hence we convert the input RGB image to HSV color space.
6. Finds the centroid (center of the coloured object) using moments.
7. Stores the previous object location in a queue.
8. The script is suitable for real time tracking as it has a very good frame rate (>32 FPS).
9. The object can be partially occluded and our script will still successfully track the object.

## Install

Run the following command:
```
uv sync
```

## Choosing a Colour

### Colour Picker

By default the program will track green objects. The colour picker script can be used to select a different colour through webcam input.

Run the following command:
```
uv run colour-picker.py
```

Click on a point in the webcam image that contains the object/colour you wish to track. This will then override the previous config settings. Back up the existing config.yml file if you wish to use it again later.

### Using Predefined Colours

There are hard-coded values for tracking objects with the following colours in the code:
- blue
- yellow
- red
- black
- white
- green
- purple
- orange

They are far from perfect. So it may be best to use the colour picker with the object you wish to track.

## Run Detection

For detecting a coloured object in a recorded video:
```
uv run main.py --video YOUR_VIDEO_FILE.mp4
```

For live detection via webcam:
```
uv run main.py
```

### Command Line Arguments

#### `-tl, --trace-length`

Controls the lenght of the red line that shows where the tracked object has been previously. Defaults to 64.

#### `-ht, --hide-trace`

Hides the trace line.

#### `-hc, --hide-circle`

Hides the circle drawn around the object.

#### `-c, --colour`

Chooses a predefined colour to track. Giving an argument for this causes the config file generated by the colour picker to be ignored.

## **Results:**
The result is great. The ball is successfully detected. Also if the ball looses the frame, we catch it later when it comes in the frame.

## **The limitations**
1. It can't track multiple objects
2. No other object of the same colour should be there, otherwise we won't be able to track successfully.
